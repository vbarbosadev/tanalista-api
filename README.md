# Tá na Lista API

API responsável pelas regras de negócio, persistência e disponibilização dos dados utilizados pelo aplicativo **Tá na Lista**.

## Sobre o projeto

O Tá na Lista é um projeto acadêmico desenvolvido no contexto das disciplinas:

- **DIM0510 — Processos de Software**
- **DIM0524 — Desenvolvimento de Sistemas para Dispositivos Móveis**

O projeto será conduzido por meio de sprints, com organização do backlog, levantamento de requisitos, documentação do processo de software, implementação, testes e revisão das entregas.

## Repositórios

O sistema está dividido em dois repositórios:

- **API/backend:** [vbarbosadev/tanalista-api](https://github.com/vbarbosadev/tanalista-api)
- **Aplicativo mobile/front-end:** [thallystorres/tanalista](https://github.com/thallystorres/tanalista)

## Responsabilidades da API

A API será responsável por:

- Implementar as regras de negócio;
- Persistir e consultar os dados do sistema;
- Disponibilizar endpoints para o aplicativo mobile;
- Validar os dados recebidos;
- Padronizar respostas e mensagens de erro;
- Integrar-se aos demais serviços definidos durante o projeto.

## Organização do desenvolvimento

O desenvolvimento será dividido em sprints.

### Sprint 0 — Descoberta e planejamento

- Definição da visão e do escopo do produto;
- Identificação dos usuários e jornadas;
- Levantamento dos requisitos funcionais e não funcionais;
- Definição do MVP;
- Modelagem inicial do domínio;
- Especificação inicial da API;
- Definição da arquitetura;
- Preparação do backlog da Sprint 1.

### Sprint 1 — Estrutura inicial e primeiro fluxo

A Sprint 1 será refinada ao final da Sprint 0. Inicialmente, deverá contemplar:

- Inicialização e configuração da API;
- Configuração do banco de dados;
- Estrutura inicial do serviço em Go;
- Documentação OpenAPI;
- Padronização de respostas e erros;
- Implementação do primeiro fluxo funcional do MVP;
- Testes automatizados;
- Integração inicial com o aplicativo mobile.

## Status

> Projeto em fase de levantamento de requisitos e definição do MVP.
